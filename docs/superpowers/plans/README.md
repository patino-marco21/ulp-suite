# Implementation plans

Each file here is the plan one piece of work was executed from, written **before** the work. Most were
executed inline and their checkboxes were not ticked afterwards: on 2026-10-01, 52 of the 55 plans still
had unchecked `- [ ]` steps. **An unchecked box is not a to-do signal.**

To find out what is current:

- the code and `git log` (`git log --oneline -- <a path the plan touches>`);
- the *Results* / *Status* section of the matching spec in [`../specs/`](../specs/);
- a **Status:** line at the top of the plan itself, where there is one — only plans that were closed out
  have it (for example `2026-09-30-query-perf-wins.md` and `2026-09-30-related-panel-and-domain-rev.md`).

For a plan with no Status line, check git history before assuming anything about whether, or how, it shipped.
